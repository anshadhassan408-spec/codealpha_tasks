# Car Price Prediction Using Machine Learning

## Project Overview

This project predicts automobile prices using machine learning regression algorithms based on vehicle specifications.

## Objectives

* Analyze car-related features.
* Perform data preprocessing and feature engineering.
* Train and compare regression models.
* Evaluate model performance.
* Visualize actual and predicted car prices.

## Technologies Used

* Python
* Google Colab
* Pandas and NumPy
* Scikit-learn
* Matplotlib

## Machine Learning Algorithms

1. Linear Regression
2. Random Forest Regression

## Evaluation Metrics

* Mean Absolute Error (MAE)
* Root Mean Squared Error (RMSE)
* R-squared (R²)

## How to Run

1. Open the notebook in Google Colab.
2. Run each cell from top to bottom.
3. Load the automobile dataset.
4. Train the models and compare their performance.
5. Enter car specifications and obtain a price prediction.
